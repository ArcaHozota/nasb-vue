# NASB1995 フロントエンド 画面デザインの決まり

## 1. 文書の目的

本書は、画面の配色・文字・大きさ・部品の見た目について、現行実装で決めている内容をまとめたものである。機能・画面遷移・通信の設計は [DesignDocument.md](DesignDocument.md) を参照する。値は2026年11月18日時点のソースを根拠とし、変更時は本書も併せて更新する。

## 2. 基本方針

- 部品は Vuetify 4 の標準部品を使い、押したときの波紋（ripple）やホバーの表示など Vuetify 本来の効果を活かす。独自の見た目に作り込むのは、標準部品で表せない場合に限る。
- ボタンの文字は大文字化しない（`VBtn` の既定クラス `text-none`）。
- 文字の大きさのクラスは Vuetify 4 の Material Design 3 の名前（`text-title-large`、`text-title-medium`、`text-body-medium`、`text-body-small`、`text-headline-medium` 等）を使う。Vuetify 3 までの `text-h6` 等は無い。
- アイコンは Material Design Icons を `src/plugins/icons.ts` に登録した SVG で使い、テンプレートでは `mdi-xxx` の名前で書く。新しいアイコンは同ファイルに追加する。
- 画面はライトテーマ固定とする。
- PC とモバイルの境目は幅768pxとする（`MOBILE_BREAKPOINT`）。

## 6. ホーム

### 6.1 PC（幅768px以上）

- 高さ64pxのヘッダーは `#fdfaf2` を背景とし、左にロゴと角の丸い検索欄（幅最大400px）、右に黄色の「ログイン」ボタン（文字の太さ800）を置く。
- ブック（左右のカードを並べた面）: 幅1190px・高さ740pxで、ヘッダーの下の余白の中央に置く。左右の幅は 36:64、間隔28px。画面が狭いときは左右に24pxずつ空けて幅を縮め、低いときはページ全体をスクロールする。
- ブックリングは古美真鍮色の楕円の上半分とし、左右のカードの間に曲ごとに1個（1ページ最大10個）置く。リングは一覧と一緒にスクロールする。
- リングは幅66px・高さ21px、線幅11pxとする。左右の接点には、幅15px・高さ13pxで内側に影を付けた楕円の穴を描き、左右とも穴の中心を対応する行の上端から行の高さの62%に合わせる。
- リングと穴には、ホームの五線譜で使うベージュと濃茶（`#b8a888`、`#c9b48d`、`#4a3426`）、補足文字の茶色（`#8a7a64`、`#6b5d4a`）を使う。
- 左のカード（一覧）: 件数の見出し、1行64pxの行を1ページ10行、下にページ送り（前・ページ数・次）。10行でスクロールなしに収まる。
- 右のカード（詳細）: 一致度のチップ、曲名、韓国語名、右上に「YouTubeで聴く」（`primary`）、調のチップ、五線譜、一致箇所の数、区切り線、歌詞。歌詞だけをカードの中でスクロールする。

### 6.2 モバイル（幅768px未満）

- ヘッダー: 高さ56px、スクロールしても上に残す。ロゴのみでログインボタンは置かない。
- 検索欄、件数の見出し、一覧のカード（行は PC と同じ部品 `HymnListRow`、左右の余白16px）、最後に聖句。
- 詳細: 画面下から出るシート（`v-bottom-sheet`、高さは画面の88%）。上に取っ手と「n / 全件数」と閉じるボタン。中身は PC の詳細と同じ部品の幅の狭い表示（`HymnDetail` の `compact`）で、YouTube ボタンは曲名の下に置き、五線譜は幅に合わせて縮める。

### 6.3 一覧の行（`HymnListRow`）

- 高さ64px。検索中は左に一致度の丸（10px）と右に一致度の文言、検索していないときは左に通し番号（臙脂）。
- 曲名は Noto Serif JP 太字、2行目に韓国語名。
- 押すと Vuetify の波紋が出る。選択中は背景を `#fbf0d6` にし、Vuetify の選択色の重ねは消す。

## 7. 管理画面

賛美歌一覧、ランダム検索、聖書章節入力、ユーザー情報更新のカード見出しと、メインメニューのカードのタイトル帯は、テーマの `info`（`#353542`）を背景にし、文字は `ivory`（`#fffff0`）の太字（700）で表示する。

### 7.1 サイドバー（`src/layouts/AdminLayout.vue`）

- 幅256px、折りたたみ時はアイコンのみの56px（Ctrl/⌘+B で切り替え）。背景は `sidebar`（`#252530`）。
- 上にロゴ、続いて項目（`v-list-item`、高さ44px、角丸なし）を並べる。項目の間に見出しや区切り線は置かない。折りたたみ時は項目名をツールチップで示す。
- 項目は押すと Vuetify の波紋が出て、ホバーで薄い背景になる。
- 選択中の項目は、左端に `ivory`（`#fffff0`）の線（3px）を置き、`info`（`#353542`）の背景と `ivory` のセミボールド（600）の文字で示す。Vuetify の選択色の重ねは消す。選んでいない項目にも透明な3pxの線を取り、文字の位置をそろえる。
- サイドバーを開いているとき、選択中の項目の右端から16px内側に `ivory`（`#fffff0`）のエルサレム十字を置く。十字は項目の高さの62%（44pxの行で約27px）とし、縦方向の中央にそろえる。
- 下にユーザー名のメニュー（個人スペース・メッセージ・ログアウト）を置く。メニューの背景には `sidebar`、ロゴと項目・ユーザーメニューの文字・アイコンには `ivory` を使う。
- 上部バーはサイドバーと同じ背景色とし、下に細い線を引く。サイドバーの開閉とログアウトのアイコンには `ivory` を使う。

| 用途                                     | 色                   |
| ---------------------------------------- | -------------------- |
| 背景（サイドバー・上部バー）             | `#252530`            |
| 選択中の背景と区切り線                   | `info`（`#353542`）  |
| 選択中の左の線                           | `ivory`（`#fffff0`） |
| ロゴ・ナビゲーション項目の文字とアイコン | `ivory`（`#fffff0`） |
| アバターの背景 / 文字                    | `info` / `ivory`     |

### 7.2 賛美歌一覧

- 検索欄はテーブルの左端にそろえ、外枠を含むテーブルの幅の38%とする。
- テーブルヘッダーは `surface`（`#f9fafb`）を背景とし、全列の見出しを濃い灰色（`#4b5563`）の太字で中央揃えにする。データ行も、番号（検索時は一致度）・曲名・韓国語名・操作の全列を中央揃えにする。
- 表の行は押すと波紋が出る（リンクのある行）。操作のボタンは text の小さいボタンで、削除は `error` 色。
- 「賛美歌情報追加」と「プレイリスト作成」のボタンは、高さ36pxにそろえてテーブルの右端に寄せる。
- 表は Vuetify の `v-data-table-server`（サーバー側でページ分割する表）とし、背景は透明（`bg-transparent`）にして、行からガラスのカードの背景が透けて見えるようにする（見出しだけ `surface` の色）。ページ送りは表の標準フッターを使う。フッターの右に「1ページの件数」（`items-per-page-text`。5・10・15件。プルダウンは枠なしの下線だけ（`underlined`）、幅64px で、Vuetify の入れ子の既定値 `VDataTableFooter` → `VSelect` を `v-defaults-provider` で指定する）、範囲と件数（例「1-10 件目 / 350件」）、最初・前・次・最後のページのボタンを並べる。件数を変えると1ページ目から表示し直す。
- 行は `#item` で自前に描き（押すと YouTube を開く・波紋・操作のボタンを保つ）、ホバーで薄い色を付ける。見出しは `header-props` で付けたクラスで上の色・太さにする。
- まだ一覧を取得できていない間はフッターを出さない。最初の読み込み中だけスケルトン行を出す。
- ページを切り替えて読み込み中の間は、フッターを出したまま前のページの行を残し、行を少し薄く（不透明度70%、0.2秒でふわっと）するだけにする。表の高さは変えない。更新に失敗して前回の一覧を出しているときは、フッターの左に「（前回取得時）」と出す。

### 7.3 賛美歌の追加・更新モーダル

- Vuetify の標準的なフォームダイアログ（タイトル・入力欄・下に右寄せのボタン）。
- モーダルのタイトルと「クラシック」のラベルは太字（700）で表示する。日本語名称・韓国語名称・リンク・歌詞のラベルはセミボールド（600）、入力内容は Noto Serif JP のセミボールド（600）で表示し、韓国語の字形には Noto Serif KR を使う。
- タイトルの下に、更新では「最終更新者：…」、追加では「すべての項目を入力してください」を出し、追加と更新でタイトル部分の高さをそろえる。
- 空欄のエラー文言は「入力してください。」とする。

### 7.4 楽譜アップロードモーダル

- タイトルと閉じるボタン、線の色は `secondary`。閉じるボタンは右上。
- 調は Vuetify の filter chip（`v-chip-group`）で、1段目7個・2段目5個に固定する（A〜E♭ / E〜A♭）。

### 7.5 ユーザー情報（`src/views/PersonalView.vue`）

- 画面全体を1枚の `v-card`（背景は白）にする。幅はサイドバーの開閉にかかわらず、見えている画面の幅の62%（`62dvw`）とし、中央に置く。上のパンくずも同じ幅にそろえる。
- 見出し（`v-card-item`）は他の画面と同じ `info` の帯に、`ivory`（`#fffff0`）の Noto Serif JP 太字（700）で「ユーザー情報更新」と出す。
- 本文（`v-card-text`）に、項目ごとの `v-card`（`variant="outlined"`）を3枚、16px 間隔で縦に並べる。各カードは左にアイコン、タイトル、サブタイトルを持つ（`prepend-icon`・`title`・`subtitle`）。
  - 基本情報（`mdi-account-outline`）: アカウント・名称・メール・生年月日。PC では2列。
  - セキュリティ（`mdi-lock-outline`）: パスワード。右に入力した文字の表示・非表示を切り替える目のボタン。
  - YouTube連携（`mdi-youtube`、赤）: 右上に状態のチップ（連携済みは `success` の tonal とチェック、未連携は既定の色）。下のフッターに、未連携なら「YouTubeと連携」（赤の tonal）、連携済みなら「連携を解除」（`error` の文字ボタン。確認してから解除）を1つだけ置く。
- 入力欄は outlined で、ラベルは欄の中（入力・フォーカスで枠の上へ移る）。フォーカスの色は `primary`。エラーがあるときだけ欄の下に出す（`hide-details="auto"`）。更新中は入力欄を無効にする。
- フッター（`v-divider` ＋ `v-card-actions`）に「廃棄」（文字ボタン）と「更新」（`primary`）を右寄せで、この順に置く。

### 7.6 聖書章節入力

- 英語・日本語の本文エディタの背景は `ivory`（`#fffff0`）とする。
- 「追加」「更新」ボタンは入力行の右端に寄せ、書・章のプルダウンと同じ高さ40pxにそろえる。操作できる状態のボタンの文字は `ivory`（`#fffff0`）の Noto Serif JP 太字（700）で表示する。

## 8. トースト・確認ダイアログ（`src/components/FeedbackHost.vue`）

### 8.1 トースト

- 画面下の中央に出す（`v-snackbar-queue`、角の丸み `sm`）。
- 背景はテーマの `info`（`#353542`）、文字は白の Noto Serif JP 太字（700）で、トーストの中央に揃える。

### 8.2 確認ダイアログ

- 確認ダイアログとモーダルの本体背景は `surface`（`#f9fafb`）とする。
- タイトルは中央、その下に色の線。
- 本文の左にアイコン（36px）を置く。警告は「!」（`mdi-alert-circle-outline`）、お知らせ・通知は「?」（`mdi-help-circle-outline`）。アイコンの色はタイトル・線と同じ。
- アイコンと本文を合わせた幅はダイアログの幅の62%とし、中央に置く。アイコンは本文の上下中央にそろえる。
- 本文の書体は Noto Serif JP の semi-bold（太さ600）。
- 本文の文字の大きさは固定せず、文の長さ（文字数）で決める。

  | 文字数 | 大きさ    |
  | ------ | --------- |
  | 20以下 | 1.156rem  |
  | 21〜40 | 1.0625rem |
  | 41〜60 | 1rem      |
  | 61以上 | 0.9375rem |

- 問いかけの本文は「〜か。」で終える（「〜か？」にしない）。
- 本文の下に区切り線を引き、その下のフッター（`v-card-actions`、余白 上下12px・左右16px）に「戻る」「OK」を右寄せで置く。ボタンの間は8px。
- ボタンは「戻る」「OK」に統一し、文字の太さは600。
- Esc は「戻る」と同じ扱い（画面に残る）。外側を押しても閉じない。開いた直後はフォーカスがカードの外側の枠にあるため、Esc はダイアログを出している間だけ画面全体で受け取る。

| 場面                                       | タイトル | 色          | アイコン |
| ------------------------------------------ | -------- | ----------- | -------- |
| 編集の破棄、プレイリスト作成、作成中の離脱 | お知らせ | `success`   | ?        |
| ログアウト、削除、YouTube連携の解除        | 警告     | `primary`   | !        |

楽譜アップロードの上書き確認で「戻る」を押すと、登録済みの楽譜をダウンロードする。

## 9. ログイン（`src/views/LoginView.vue`）

背景画像の色とガラスの透け感を活かした、青灰色のスモークガラスカードを中央に置く。背景の大きな文字がフォームの読み取りを妨げないよう、カード内の背景をぼかし、ラベル・入力文字との明暗差を付ける。入力欄は Vuetify 4 の outlined の `v-text-field` で、ラベルを欄の中に置く（入力・フォーカスで枠の上へ移る）。

| 用途           | 指定                                                                                                                                                                                                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 背景           | `src/assets/login-bg.webp` を画面全体に固定し、`object-fit: cover` で表示                                                                                                                                                                                            |
| カード         | 幅360px、最大幅は画面幅から32pxを引いた値、内側余白は上下30px・左右28px、角丸20px。カードの中の文字は白                                                                                                                                                              |
| ガラス         | `rgba(15, 23, 42, 0.66)`（不透明度66%）、`blur(24px) saturate(115%)`                                                                                                                                                                                                 |
| 枠・影         | 白60%の1px枠、外側に影・内側上辺に白35%のハイライト                                                                                                                                                                                                                  |
| 見出し         | `NASB1995` を中央揃え、白、1.625rem、太さ900。下の余白22px                                                                                                                                                                                                           |
| ラベル         | 欄の中（`label`）。白75%、フォーカス中はクリーム色（`#f3e3c3`）。濃さなどの見た目は Vuetify の標準のまま                                                                                                                                                             |
| 入力欄         | outlined・`theme="dark"`（Vuetify の暗い背景用の配色）。高さ・角丸は Vuetify の既定、背景なし（カードのガラスが透ける）。入力文字はカードの文字色（白）を受け継ぐ。欄の下の余白20px。左にアイコン（ユーザー名 `mdi-account-outline`、パスワード `mdi-lock-outline`） |
| 入力欄の枠     | 通常は白75%の細い枠、フォーカス時はクリーム色（`#f3e3c3`）の太い枠                                                                                                                                                                                                   |
| 目のボタン     | パスワード欄の右に置き、押すと入力した文字を表示・非表示にする（`mdi-eye-outline` / `mdi-eye-off-outline`）。送信はしない                                                                                                                                            |
| 自動入力       | ブラウザの自動入力で欄が水色に塗られないようにし、文字は白のままにする                                                                                                                                                                                               |
| 入力チェック   | 送信したときに、ユーザー名・パスワードが空なら欄ごとに「入力してください。」を出し、サーバーへは送らない（Vuetify の `v-form` と `rules`、`validate-on="submit"`）。認証の失敗は従来どおりカードのエラーで示す                                                       |
| ログインボタン | `primary`（`#800020`）、文字は白・太さ800、幅いっぱい、高さ46px、角丸6px、白33%の1px枠                                                                                                                                                                               |
| エラー         | 淡い赤の背景（白に近い `rgba(254, 242, 242, 0.95)`）に、Vuetify 標準のエラー色で表示                                                                                                                                                                                 |
| フォント       | Noto Sans JP。全体用400・500・700に加え、見出し用900とボタン用800をログイン画面で読み込む                                                                                                                                                                            |

画面の上下に24pxの余白を取り、高さが足りない場合はページをスクロールできるようにする。

ログイン送信中は、次の表示に切り替える。

- 待機表示は送信開始から最低3300ms続ける。認証処理が3300msを超える場合は完了まで待ち、応答後に追加で3300ms待たない。成功・失敗のどちらにも適用する。
- カードの背景・枠・影をまとめた外観の不透明度を33%にする。背景色は待機中だけ不透明（100%）にしてから外観全体を33%にし、実効的な背景色の不透明度も33%とする（通常時の66%のまま外観全体を33%にすると約22%まで薄くなるため、そうしない）。背景の文字・風景が見えるよう、待機中は背景ぼかしを外す。
- 見出し・ラベル・入力欄は、配置の高さを保って非表示にする。入力欄を無効化し、値は保持する。
- ログインボタンは不透明度100%・通常の `primary` 色を保ち、中央に円形の回転インジケーターだけを表示する。画面上の文言は表示せず、読み上げ用に処理中の状態を伝える。送信中の再操作による重複要求を防ぐ。
- 失敗時は通常のガラス表示・入力欄を復元し、エラーを表示して再入力・再試行を可能にする。
